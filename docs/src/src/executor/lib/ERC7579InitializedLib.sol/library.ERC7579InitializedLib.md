# ERC7579InitializedLib

[Git Source](https://github.com/rhinestonewtf/compact-utils/blob/1c4e4566192e5b39577aef085af405aca2f20a9d/src/executor/lib/ERC7579InitializedLib.sol)

**Author:**
Rhinestone (zeroknots.eth, highskore.eth)

Library for managing ERC7579 module initialization state in a gas-efficient manner

This library provides deterministic storage slot generation and state management for
tracking whether ERC7579 modules have been initialized for specific accounts.
The library uses a collision-resistant storage pattern where each account gets a unique
storage slot derived from keccak256(SLOT, account). This ensures complete isolation
between different accounts' initialization states.
Gas optimizations:

- Uses EVM scratch space (0x00-0x3F) instead of allocating memory
- Direct assembly for storage operations
- No unnecessary memory clearing (scratch space is temporary by design)

**Note:**
security: All storage slots are deterministically derived and collision-resistant

## State Variables

### SLOT

Base storage slot derived from keccak256("ERC7579Module.Initialized.Storage")

This constant ensures consistent storage location across all deployments
The value 0xd29d5db3 is truncated from the full keccak256 hash

```solidity
uint256 internal constant SLOT = 0xd29d5db3
```

## Functions

### moduleSlot

Computes a unique storage slot for tracking module initialization per account

Generates a deterministic storage slot using keccak256(SLOT || account) pattern.
This ensures each account has an isolated storage location that cannot collide
with other accounts or storage variables.
The function uses EVM scratch space (0x00-0x3F) for temporary storage during
hash computation, avoiding memory allocation overhead. The scratch space holds:

- 0x00-0x1F: SLOT constant (base storage identifier)
- 0x20-0x3F: account address (right-padded to 32 bytes)

**Notes:**

- gas: ~200 gas due to keccak256 operation and scratch space usage

- security: Collision-resistant due to keccak256 properties and unique inputs

```solidity
function moduleSlot(address account) internal pure returns (bytes32 _slot);
```

**Parameters**

| Name      | Type      | Description                                      |
| --------- | --------- | ------------------------------------------------ |
| `account` | `address` | The address for which to generate a storage slot |

**Returns**

| Name    | Type      | Description                                                            |
| ------- | --------- | ---------------------------------------------------------------------- |
| `_slot` | `bytes32` | The deterministic storage slot for this account's initialization state |

### set

Stores a value at the specified storage slot

Direct assembly implementation for gas-efficient storage writes.
Typically used to mark a module as initialized (value = 1) or
reset initialization state (value = 0).

**Notes:**

- gas: ~20000 gas for cold storage write, ~5000 for warm storage

- usage: Common pattern: `set(moduleSlot(account), 1)` to mark as initialized

```solidity
function set(bytes32 slot, uint256 value) internal;
```

**Parameters**

| Name    | Type      | Description                                                         |
| ------- | --------- | ------------------------------------------------------------------- |
| `slot`  | `bytes32` | The storage slot to write to (generated by moduleSlot)              |
| `value` | `uint256` | The value to store (usually 0 for uninitialized, 1 for initialized) |

### get

Retrieves the value stored at the specified storage slot

Direct assembly implementation for gas-efficient storage reads.
Returns 0 for uninitialized slots (EVM default) or the previously set value.

**Notes:**

- gas: ~2100 gas for cold storage read, ~100 for warm storage

- usage: Common pattern: `if (get(moduleSlot(account)) == 0)` to check initialization

```solidity
function get(bytes32 slot) internal view returns (uint256 value);
```

**Parameters**

| Name   | Type      | Description                                             |
| ------ | --------- | ------------------------------------------------------- |
| `slot` | `bytes32` | The storage slot to read from (generated by moduleSlot) |

**Returns**

| Name    | Type      | Description                                                  |
| ------- | --------- | ------------------------------------------------------------ |
| `value` | `uint256` | The stored value (0 if never set, or the last value written) |
